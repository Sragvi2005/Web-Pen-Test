EXECUTION SEQUENCE
01
Target Resolution
URL is parsed, domain extracted, HTTPS scheme validated. A persistent session is established with a custom User-Agent to bypass trivial bot-detection during the audit window.
VulnerabilityScanner(target_url, max_threads)
↓
02
SSL/TLS Inspection
Direct socket connection to port 443. Captures TLS negotiated version and cipher suite. Flags TLS 1.0, 1.1, SSLv3, SSLv2 as deprecated. Certificate expiry computed — alerts if expired or <15 days from expiry.
ssl.create_default_context() → sock.getpeercert()
↓
03
HTTP Header Audit
GET request to root. Response headers are cross-checked against five OWASP-recommended headers. Each missing header is scored independently with a CVSS v3.1 vector, not averaged.
CSP · HSTS · X-Frame-Options · XCTO · Referrer-Policy
↓
04
CORS Policy Probe
Forged Origin header is injected. Response is checked for arbitrary reflection. If Access-Control-Allow-Credentials: true is also present, severity escalates to Critical — this is a credential exfiltration vector.
Origin: https://evil-attacker-domain.com
↓
05
Concurrent Endpoint Discovery
ThreadPoolExecutor distributes 10 common sensitive paths across worker threads. HTTP 200 responses are flagged. Paths like /.env, /.git/HEAD, /.aws/credentials score High; others score Medium.
/.env · /.git/HEAD · /swagger.json · /.aws/credentials · /backup.sql
↓
06
Reflected XSS Detection
A safe test string <SecTest123> is URL-encoded and injected as query parameter ?q=. If the raw unescaped string appears in the response body, unsanitized input reflection is confirmed.
/?q=%3CSecTest123%3E → grep response.text

OUTPUT FORMATS

Three report formats. Zero manual work.

.json
Structured Data
Machine-readable findings. Pipe into SIEM, Jira, or custom dashboards. Each finding includes title, type, severity, CVSS score, technical detail, and remediation action.

.html
Executive Report
Browser-ready report with risk summary cards, vulnerability overview table, and detailed per-finding remediation guidance. Self-contained — no external dependencies.

.pdf
Print-Ready PDF
